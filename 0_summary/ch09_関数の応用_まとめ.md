# 第9章 関数の応用（ラムダ・高階関数・内包表記・再帰・デコレータ）まとめ

> ★ = 特に重要な項目

## ① 章の目的
関数を「データとして渡す・返す」発想を身につけ、短く読みやすいコードを書けるようにすることです。

## ② 重要項目

| 項目 | 書き方 | ポイント | 学習状況 |
|---|---|---|---|
| ラムダ式 | `lambda x: x * 2` | 1行で書ける名前のない関数 | ✅ |
| ★高階関数 | `map(f, list)` / `filter(f, list)` | 関数を引数に受け取る関数 | ✅ |
| ★sortedのkey | `sorted(d.items(), key=lambda x: x[1])` | 辞書を値で並べ替える定番 | ✅ |
| ★内包表記 | `[x*2 for x in nums if x > 0]` | リスト・辞書・セットで使える | ✅ |
| 辞書内包表記 | `{k: v for k, v in d.items()}` | 辞書の変換・絞り込み | ✅ |
| 再帰関数 | 関数が自分自身を呼ぶ | **終了条件**が必須 | 🔶 これから |
| デコレータ | `@decorator` | 関数を受け取り、機能を足した関数を返す | ⬜ これから |

## ③ 基本コード

```python
scores = {"国語": 80, "数学": 92, "英語": 75}

# 値の大きい順に並べ替え（sorted + lambda）
ranking = sorted(scores.items(), key=lambda x: x[1], reverse=True)

# 80点以上だけ残す（辞書内包表記）
passed = {k: v for k, v in scores.items() if v >= 80}

# map / filter は list() で中身を確認
nums = [1, -2, 3]
doubled = list(map(lambda x: x * 2, nums))      # [2, -4, 6]
positive = list(filter(lambda x: x > 0, nums))  # [1, 3]

# 再帰（予習）：階乗
def factorial(n):
    if n <= 1:          # 終了条件
        return 1
    return n * factorial(n - 1)

# デコレータ（予習）：関数の前後に処理を足す
def log(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} を実行します")
        return func(*args, **kwargs)
    return wrapper

@log
def hello():
    print("こんにちは")
```

## ④ よくあるミス
1. `map`/`filter`の結果をそのまま`print`して`<map object>`と表示される → `list()`で囲みます。
2. 内包表記に条件を詰め込みすぎて読めなくなる → 2段以上ならfor文に戻します。
3. 再帰で終了条件を忘れ、RecursionErrorになる。

## ⑤ 前後の章とのつながり
- **第8章から**：デコレータは`*args`・`**kwargs`とスコープ（関数の中の関数）の知識を総動員します。
- **第10章へ**：クラスでは`@property`や`@classmethod`などデコレータの記法が登場します。
