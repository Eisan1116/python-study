# 第7章 ファイル入出力・標準モジュール まとめ

> ★ = 特に重要な項目

## ① 章の目的
プログラムの外（ファイル）にデータを保存・読み込みし、日付や乱数などの便利な標準機能を使えるようにすることです。

## ② 重要項目

| 項目 | 書き方 | ポイント |
|---|---|---|
| パス操作 | `pathlib.Path("data/a.txt")` | 相対パスは**実行場所**が基準になる |
| ★開く | `open(path, "r", encoding="utf-8")` | モード：`r`読込・`w`上書き・`a`追記 |
| ★with文 | `with open(...) as f:` | ブロックを抜けると**自動でclose**される |
| 読み込み | `read()` / `readline()` / `for line in f` | 大きいファイルは1行ずつ読むのが安全 |
| 書き込み | `f.write("文字列\n")` | 改行は自分で付ける |
| ファイル操作 | `shutil.copy()` / `shutil.move()` | コピー・移動・バックアップに使う |
| ★JSON | `json.dump()` / `json.load()` | 日本語は`ensure_ascii=False` |
| JSON（文字列） | `json.dumps()` / `json.loads()` | 末尾の`s`は「文字列(string)」との変換 |
| 日付 | `datetime.now().strftime("%Y-%m-%d")` | 文字列→日付は`strptime` |
| 乱数 | `random.randint(1, 6)` / `choice` / `shuffle` | `randint`は両端を含む |
| 数学 | `math.sqrt` / `ceil` / `floor` / `math.pi` | `import math`してから使う |

## ③ 基本コード

```python
import json
from datetime import datetime

log = {"date": datetime.now().strftime("%Y-%m-%d"), "minutes": 90}

# 書き込み
with open("log.json", "w", encoding="utf-8") as f:
    json.dump(log, f, ensure_ascii=False, indent=2)

# 読み込み
with open("log.json", "r", encoding="utf-8") as f:
    data = json.load(f)
print(data["minutes"])   # 90

# テキストファイルを1行ずつ読む
with open("memo.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())   # 末尾の改行を除去
```

## ④ よくあるミス
1. `"w"`モードで開いて、既存の内容を消してしまう → 追記なら`"a"`です。
2. `encoding`を省略し、Windowsで文字化けする → 常に`utf-8`を指定します。
3. ファイルが見つからない（FileNotFoundError） → VSCodeの実行フォルダ（カレントディレクトリ）を確認します。
4. `json.dump`と`json.dumps`を取り違える → ファイルに書くなら`dump`、文字列が欲しいなら`dumps`です。
