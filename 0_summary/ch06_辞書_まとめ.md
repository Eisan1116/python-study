# 第6章 辞書（dict）まとめ

> ★ = 特に重要な項目

## ① 章の目的
「キー」と「値」をペアで管理するデータ構造を使いこなすことです。リストが「番号で取り出す」のに対し、辞書は「名前で取り出す」ものです。

## ② 重要項目

| 項目 | 書き方 | ポイント |
|---|---|---|
| 作成 | `d = {"apple": 100}` / `dict()` | キーは文字列・数値・タプルなど**変更できない型**のみ |
| ★取得 | `d["apple"]` / `d.get("apple", 0)` | `[]`は存在しないキーで**KeyError**、`get`は既定値を返す |
| 追加・更新 | `d["banana"] = 200` / `d.update(...)` | 同じキーなら上書きされる |
| 削除 | `del d["apple"]` / `d.pop("apple")` | `pop`は削除した値を返す |
| 存在確認 | `"apple" in d` | キーを調べる（値ではない） |
| ★ループ | `keys()` / `values()` / `items()` | `items()`でキーと値を同時に取り出す |
| 応用 | `setdefault()`、辞書のリスト、ネスト | JSONと同じ形でデータを管理できる |

## ③ 基本コード

```python
scores = {"国語": 80, "数学": 92}
scores["英語"] = 75                     # 追加
print(scores.get("理科", 0))            # 0（KeyErrorにならない）

for subject, score in scores.items():   # キーと値を同時に
    print(f"{subject}: {score}点")

# 応用：辞書のリスト（JSONと同じ形）
records = [
    {"date": "2026-10-01", "item": "昼食", "price": 650},
    {"date": "2026-10-01", "item": "参考書", "price": 2800},
]
total = 0
for r in records:
    total += r["price"]
print(total)   # 3450
```

## ④ よくあるミス
1. 存在しないキーを`d[key]`で読み、KeyErrorになる → `get()`か`in`で確認します。
2. ループ中に辞書のキーを追加・削除してエラーになる → `list(d.keys())`でコピーしてから回します。
3. `in`で値を探そうとしてしまう → `in d`はキーだけを調べます。値なら`in d.values()`です。

## ⑤ 前後の章とのつながり
- **第7章へ**：JSONは「辞書をそのままファイルに保存する形式」です。辞書を理解していれば、JSONはほぼ同じ感覚で扱えます。
- **第9章へ**：辞書内包表記や`sorted(d.items(), key=lambda x: x[1])`で、辞書の変換・並べ替えができるようになります。
