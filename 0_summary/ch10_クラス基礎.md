# 第10章 クラス基礎（クラス・インスタンス・クラス変数・カプセル化）まとめ

> ★ = 特に重要な項目

## ① 章の目的
「データ」と「そのデータを扱う処理」を1つにまとめ、設計図（クラス）から実物（インスタンス）をいくつでも作れるようにすることです。「`self` の役割」と「データを外から勝手に触らせない仕組み（カプセル化）」が二本柱です。

## ② 重要項目

| 項目 | 書き方 | ポイント |
|---|---|---|
| クラス定義 | `class Record:` | クラス名は**大文字始まり**が慣習 |
| インスタンス作成 | `r = Record("昼食", 800)` | 1つのクラスから別々の実体をいくつでも作れる |
| ★`__init__` | `def __init__(self, item, amount):` | インスタンス作成時に**自動で**呼ばれる |
| ★`self` | `self.amount = amount` | 「そのインスタンス自身」。`self.` を付けないとローカル変数で消える |
| メソッド | `def show(self):` → `r.show()` | 第1引数は必ず `self`。呼ぶときは渡さない |
| ★クラス変数 | クラス直下に `count = 0` | 全インスタンスで**共有**。変更は必ず `クラス名.変数名` |
| インスタンス変数 | `self.〇〇` | インスタンスごとに別々の値 |
| 属性の探す順番 | インスタンス → クラス | インスタンスに同名があればそちらが優先される |
| 非公開の慣習 | `self._amount` | 「内部用なので触らない」という目印（`__` は第11章で） |
| ★`@property` | 読む係・書く係をセットで定義 | `r.amount` / `r.amount = 100` の形のまま裏でチェックできる |
| 読み取り専用 | setterを書かない | 代入すると `AttributeError` |

## ③ 基本コード

```python
# ★@property のテンプレート
class クラス名:
    def __init__(self, 値):
        self._属性名 = 値                # 本物のデータ（金庫）

    @property
    def 属性名(self):                    # 読む係（窓口）
        return self._属性名

    @属性名.setter
    def 属性名(self, value):             # 書く係（窓口）※省略すると読み取り専用
        # ここにチェックを書く
        self._属性名 = value
```

```python
# 家計簿（総合診断 ex10_review.py）
class Record:
    count = 0                                   # クラス変数（件数）

    def __init__(self, date, item, amount):
        Record.count += 1                       # クラス名で更新
        self.number = Record.count
        self.date = date
        self.item = item
        self._amount = 0                        # 先に金庫へ初期値
        self.amount = amount                    # setterのチェックを通す

    @property
    def amount(self):
        return self._amount

    @amount.setter
    def amount(self, value):
        if not isinstance(value, int) or value < 0:
            print("金額は0以上の整数で入力してください")
            return
        self._amount = value

    def show(self):
        print(f"No.{self.number} {self.date} {self.item} {self.amount}円")


class Kakeibo:
    def __init__(self, owner):
        self.owner = owner
        self._records = []                      # インスタンスのリスト

    def add(self, record):
        self._records.append(record)

    @property
    def total(self):                            # 読み取り専用・毎回計算
        total = 0
        for record in self._records:
            total += record.amount
        return total
```

## ④ よくあるミス
1. `__init__` の中で `count = 0` と書き、`self.` を付け忘れる → ローカル変数になり、メソッドから使えず `AttributeError` になります。
2. メソッドを定義しただけで呼び出していない → 関数と同じで、`r.show()` と呼んで初めて実行されます。
3. クラス変数を `self.count += 1` で更新する → インスタンスに新しい変数が作られ、`クラス名.count` は変わりません。
4. ★`@property` の中で `return self.amount` と書く → 窓口の中で窓口を呼び続け、**RecursionError** になります。中では必ず `self._amount`（金庫）を触ります。
5. 読み取り専用の属性に `__init__` の中で `self.total = 0` と代入する → setterがないので `AttributeError` です。
6. `__init__` で `self._amount = amount` と金庫に直接入れる → setterのチェックを通らず、不正な値が入ります。チェックしたい値は `self.amount = amount` で入れます。
7. `print` でエラーを表示したあと `return` を忘れる → そのまま下の代入まで進んでしまいます。
8. 条件の境界を間違える（`< 0` と `<= 0`）→ ちょうど境目の値（0など）を入れて確認します。

## ⑤ 前後の章とのつながり
- **第6章から**：辞書で表していた「記録1件分」が、クラスでは**データと処理をまとめた1つの型**になります。
- **第8章から**：`self.` を付けないとローカル変数になるのは、関数のスコープと同じ仕組みです。
- **第9章から**：`@property` はデコレータの記法です。「関数に役割を付け加える目印」として使っています。
- **第11章へ**：`Record` をもとに「収入」「支出」のような似たクラスを効率よく作る**継承**を学びます。
