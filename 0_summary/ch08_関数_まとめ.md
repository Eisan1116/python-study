# 第8章 関数 まとめ

> ★ = 特に重要な項目

## ① 章の目的
処理に名前を付けてまとめ、再利用・整理できるようにすることです。「引数の受け取り方」と「変数がどこから見えるか（スコープ）」が二本柱です。

## ② 重要項目

| 項目 | 書き方 | ポイント |
|---|---|---|
| 定義 | `def add(a, b): return a + b` | `return`がないと`None`を返す |
| 位置・キーワード引数 | `add(1, b=2)` | キーワード引数は位置引数の後ろ |
| ★デフォルト引数 | `def greet(name="ゲスト"):` | **リストや辞書を既定値にしない** |
| 可変長（位置） | `def f(*args):` | `args`は**タプル**で受け取る |
| 可変長（キーワード） | `def f(**kwargs):` | `kwargs`は**辞書**で受け取る |
| 引数の並び順 | 位置 → `*args` → デフォルト → `**kwargs` | 順番を間違えると構文エラー |
| ★スコープ | LEGB（ローカル→外側→グローバル→組み込み） | 関数内で代入した変数はローカル扱い |
| global / nonlocal | `global count` | 外側の変数を書き換えるときだけ使う |

## ③ 基本コード

```python
def total(*prices, tax=0.1, **options):
    subtotal = sum(prices)
    if options.get("member"):
        subtotal *= 0.9
    return round(subtotal * (1 + tax))

print(total(100, 200, member=True))   # 297

# ミュータブルなデフォルト引数の正しい書き方
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

## ④ よくあるミス
1. `def f(items=[])`と書くと、呼び出すたびに**同じリストが使い回される** → `items=None`にして中で`[]`を作ります。
2. 関数内でグローバル変数に`+=`してUnboundLocalErrorになる → `global`に頼らず、引数と戻り値で受け渡すのが基本です。
3. `print`と`return`を混同する → 値を後で使うなら必ず`return`です。
